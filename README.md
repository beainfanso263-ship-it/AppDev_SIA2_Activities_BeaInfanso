Description of the repository

This repository contains a compilation of all laboratory activities and projects completed during the semester for Application Development and System Integration and Architecture 2.

List and explanation of the activities

**SIA2
* Activity 1 – This activity is a UML Diagram Design Project for Washmate , a web-based laundromat management platform designed to replace manual operations with an automated system. The document details how the application centralizes operations like order management, real-time laundry status tracking, payment processing, and report generation. It identifies the specific roles and permissions for three main system actors—Administrators, Staff, and Customers —and outlines six primary system functions. Ultimately, the project features a visual Use Case Diagram along with a short explanation mapping out exactly how each user type interacts with the platform's core functional modules. 

* Activity 2 – Focuses on basic routing, controller logic, and passing hardcoded datasets to Blade templates to build a static navigation flow (List $\rightarrow$ Detail $\rightarrow$ Back). For this assignment, the user has selected a Coffee Menu List theme.  

* Activity 3 – Elevates backend implementation by requiring database configuration, schema migrations, and full resource controller CRUD (Create, Read, Update, Delete) operations using a live database. For this assignment, the user has selected a Student Quiz Record System theme.

* Activity 4 – Concentrates on frontend-to-backend data submission, applying secure validation rules within the controller, implementing CSRF protection, and handling dynamic error reporting within Blade views. For this assignment, the user has selected an Event Booking Form theme.

* Activity 5 – The project utilizes Laravel Breeze for user authentication , implementing a custom registration field that handles role-based profile access for administrators and users. The platform showcases API integration by successfully serving data from its own custom JSON endpoint (/api/users) to display a searchable table of registered users. Additionally, it consumes the Open-Meteo public API to fetch and display live weather conditions and a 5-day forecast for Silago, Southern Leyte , providing relevant data to support event planning operations.
